# 動きとかわいさを強化（v370）

既存10スタイルの写真合成を更新。ハナは重なる写真カード、ハート、光沢の泡と星。ポップは縦に弾む写真・広がる星・リズムリング。ストリートは左右のスライドと回転する背景。雑誌風・フィルム・トラベルはサブ写真と白縁カードのコラージュ。シネマ・エアリーはズームと流れる光、モノクロは金の額縁と輝き。写真は等比率で全体を描画し、生成AIや顔・身体の変形は使わない。

華やかさを3段階から選択（華やかが初期値）。無音の動くプレビューで実際の合成を20fps上限で確認できる。画面非表示・折りたたみ・本番録画開始時はプレビュー停止。完成MP4にも同じ演出と強さを反映。既存の音楽解析・公式音源の取り扱い・字幕・投稿同意フローは維持。

検証：動きの数値と写真の収まりを含む新規2件、音楽解析・字幕15件、Instagram音楽・写真キャッシュ13件の計30件通過。Chromeで10スタイルの描画を目視確認。同じ合成エンジンで1080×1920、15.003秒、約8.1MBのMP4を制作。ブラウザ拡張のファイル選択制限のため、今回はサイト内の既存確認画像を使う描画ハーネスで検証し、OPSの写真選択から保存までの再検証とiPhone実機検証は未実施。

追加API・環境変数・DB変更なし。描画負荷は旧版より増えるため、低性能端末では「やさしく」を推奨。公式音楽のBPM自動取得や正確な拍の同期を追加したものではない。
