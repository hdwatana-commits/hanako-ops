# 編集スタイルと音楽に合わせた編集（v368）

## 追加スタイル
既存のハナ・シネマ・ポップに、雑誌風エディトリアル、クリーン・ミニマル、パリ・フィルム、エアリー・ソフト、モノクロ・ラグジュアリー、ストリート・ビート、トラベル・ダイアリーを追加。合計10スタイルと「おまかせ」。写真を選ぶとその写真でスタイルカードを表示し、静止プレビューも開ける。スマホは見本を横スクロール、PCは一覧表示。
人物を再生成せず、写真全体を余白内に収めたまま微小ズーム・パン・色調・額縁・粒子・光を合成する。シネマなどはクロスフェード、ストリートは短い切替と弱い拍ズーム、雑誌風/旅は白い余白を使用。色調変化が不要な場合はハナを選ぶ。モノクロは明示的に選択した場合のみ。

## 音楽に合わせる仕組み
- アップロード音声の選択区間を20ms単位で解析。全体・低音・高音の立ち上がりからピークを検出し、BPM候補と周期への適合率を計算。信頼度が低い場合は音声同期とは表示しない。
- 検出した拍を基準にビート列を作り、欠けた拍を推定補完。区間ごとのRMSエネルギーを相対評価する。
- 強い区間では写真切替を速く、静かな区間では保持を長くする。色やフレームだけでなく、スタイルごとに拍数・最低保持時間・切替時間も異なる。全4枚の写真が出るよう、保持時間に上限を設ける。
- 「おまかせ」はBPMと強弱からスタイルを選択。遅い曲はエアリー、速く強弱の大きい曲はストリートなど。曲名・歌詞・音楽ジャンルを認識した選択ではない。
- 「音楽に合わせた編集を確認」で推定BPM、選択スタイル、カット数を表示。生成時に同じ計画を固定し、カット・クロスフェード・ズーム・拍の光へ反映する。
- 低信頼のBPM、倍/半分のテンポ、シンコペーションは誤推定し得る。BPMと拍位置の手動補正を維持する。

## Instagram公式音楽
公式楽曲は音声を編集用にダウンロードせず、試聴と投稿時の音源付与を維持する。BPMの自動取得は実装していない。曲のBPMを入力するか、試聴しながら拍に4回以上タップするとテンポを計算し、その速さで編集する。選択楽曲を変えると曲固有のテンポ指定をリセットする。
これは実音声の自動解析ではなく、開始位置・拍の位相・字幕と歌声の一致は保証しない。UIと生成結果に「指定」「タップ」「仮テンポ」を区別して表示。詳細欄のBPM指定がある場合はそちらを優先する。公式音源付き完成プレビューの制限や無音MP4保存の仕様も変えない。
