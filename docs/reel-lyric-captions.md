# 歌詞に合わせた字幕（v366）

## 操作
リール制作の「♡ 歌詞に合わせて、かわいい字幕を入れる」をONにする。
1. 動画に使う部分の歌詞を1行ずつ貼る（利用権のある文章のみ）。
2. 歌詞の利用権を確認し、「歌詞の字幕を自動配置」を押す。
3. プレビューして、必要に応じて「再生して、歌い出しをタップで合わせる」。各行を歌い始める瞬間に行送りボタンを押し、全行を合わせると確定する。
4. ふわふわピンク／キラキラホワイト／カラオケ風ポップを選択。リール制作で字幕入りMP4を出力する。

## タイミングの決め方
- 通常の歌詞：動画内の表示範囲へ文字量に応じて割り付ける。利用権のある音声ファイルでは、信頼度が十分な検出ビートに近い行境界へ調整する。これは推定であり、歌声・単語を認識した強制アラインメントではない。
- LRC：`[00:05.25]歌詞` のタイミングを使用する。次の時刻まで表示。空の時刻行では字幕が消える。1行に複数の時刻がある場合は繰り返し表示。重複する時刻・不正な時刻は拒否する。
- 全曲LRC：「音楽ファイルの先頭を0秒」を選ぶと、音楽の開始位置を差し引き動画の時刻へ変換する。動画外の区間を切り取り、動画開始時点で歌唱中の行も表示する。
- LRCの非ゼロoffsetタグは解釈の混同を避けて拒否し、UIの「字幕全体をずらす」で補正する。
- 行別の開始・終了を編集可能。手動時刻・タップ時刻は生成時に自動配置で上書きしない。手動配置後の全体オフセットは手動時刻へ差分適用する。入力歌詞や表示範囲が変わったときは時刻を作り直す旨を表示する。
- 途中のタップ合わせは確定しない。字幕を生成するには全行を合わせるか、自動配置で元のタイミングへ戻す必要がある。

## 描画
字幕はCanvasでMP4映像へ焼き込む。1行ずつ切替、フェード、軽いポップ・浮き上がり、ハート／キラキラ、小さな縁取り、ピンクの丸いプレート。日本語長文は文字サイズを調整し最大3段に折り返す。上／中央／中央より下の3位置。Instagramの端のUIと重なりにくい領域へ制限する。
カラオケ風の色変化は各字幕区間内の進行に応じた視覚演出で、単語単位の歌唱時刻ではない。
従来の単一区間テキストも維持する。両方使うときは位置が重ならないようプレビューで確認する。
最大30行、1行60文字、全体2400文字。LRCは64KB以下。字幕は動画内・1行0.1秒以上で重なりなし。字幕OFF時は従来動作。

## 音楽方式による違い
音声ファイル方式は同じ音声を再生しながら字幕をプレビュー・タップ補正できる。Instagram公式音楽と後付け方式は、音声を動画編集用に取得しないため正確な歌詞同期を保証しない。表示は動画内の時刻に基づく。公式APIから歌詞を取得する実装、歌詞の検索・スクレイピング、試聴音源のダウンロード、歌声の自動文字起こしは追加していない。
