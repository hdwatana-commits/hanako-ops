# SNS投稿画面の刷新（v390 / 2026-11-01）

既存のSNS投稿画面を、目的別メニューと段階別の作成画面に整理した。投稿・画像生成・認証・クラウド保存の処理は既存のものを使う。

## 追加した使い方

- 冒頭で「Instagramの写真投稿」「Threadsの写真投稿」「2択で聞く投稿」「写真集」「自由に企画」「商品紹介」を選ぶ。
- 「企画 → 写真・見た目 → 文章 → 完成・保存」で作成。「毎日の下書き」「こだわり設定・学習」も独立したメニューから開ける。
- 本人写真を写真設定の最初へ移し、服・髪型・表情・場所・構図などをまとめた。商品紹介の設定は商品モードで表示する。
- 投稿文を作成すると完成画面へ進む。直接編集・文字数表示・コピー・下書き保存・予定登録・既存の投稿操作を利用できる。
- 右の要約で選択した見た目、本人写真・本文・画像指示の準備状況を確認できる。条件変更時は画像指示の更新を案内する。
- 検索付き選択画面をシーン・髪型・構図・光などへ拡張。カテゴリ、全角/半角・かな検索、お気に入り30件、最近使った12件、選択中の表示に対応。
- お気に入り・最近使った項目はこの端末のlocalStorageのみ。正規設定とハナ用の同じ選択項目では履歴を共有する。
- 投稿形式による選択制限を検索結果にも反映。変更できない枚数などは「固定されています」と表示する。
- PCの細い3カラム・二重スクロールを解消。スマホではメニューを2段にして全項目を表示し、ヘッダーの高さに合わせて追従位置を調整する。

同じモードの再クリックと画面タブの移動は選択した設定を保つ。別の投稿形式へ変更した場合は、既存のモード切替処理に従って、その形式のおすすめ設定・枚数・場所の制約を反映する。

## 変更ファイル

- `sns-studio.mjs`：既存要素とイベントを保った画面整理、モード選択、手順ナビ、要約、完成稿への移動、文字数、SNS画面への直接リンク。
- `sns-studio.css`：SNS画面に限定したカード・段階別レイアウト・モバイル表示・選択ダイアログ。
- `app.js`：既存の選択ダイアログの機能拡張と、保存・クラウド復元時に新UIを更新するイベント。生成・公開処理の変更なし。
- `index.html`、`sw.js`、`version.json`：追加ファイルの読み込み、オフラインキャッシュ、本番バージョン更新。
- `tests/hanako-picker.test.mjs`：正規設定とミラーの連携、選択制約、検索、履歴、お気に入り、フォーカス復帰の回帰テスト。
