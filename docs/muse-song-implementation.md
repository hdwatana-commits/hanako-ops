# 楽曲連動MUSEリール制作・実装メモ

## 保存と既存構成

既存の静的HTML/JavaScript PWAを拡張。新規アプリ・DBテーブル・スキーマ移行・有料APIは追加していません。既存OPSの `state.museSongLibrary` に解析メタデータを置き、既存のlocalStorage保存、Supabaseの所有者別JSON状態同期、JSONバックアップを再利用します。新規のAPIキーや権限は不要です。

本人画像・スタイリングは既存のMUSE画面から読み取り、従来の写真スライドリールと共存します。音声本体はローカルでデコードし、端末メモリと一時Blob URLだけで保持。同期・バックアップ・サーバー送信には含めません。「この画面から音源を削除」または画面終了で破棄します。

## 追加・変更ファイル

- `muse-song-catalog.mjs`：初期20曲、正式書誌、公式/正規配信・YouTube参照。音源情報は全曲未確認で初期化。
- `muse-song-library.mjs`：バージョン別メタデータ、試聴確認状態、キャッシュ、復元、音声本体の除外。
- `muse-song-analysis.mjs`：既存 `reel-engine.mjs` の拍解析と、4秒単位の反復・音量・音色特徴からサビ候補を推定。
- `muse-song-choreography.mjs`：身体・左右手足・顔・目線・加減速・終了姿勢をカット別に構成。楽曲/動画時刻と音響アクセントを対応。英語動画指示、日本語画像準備・編集指示。
- `muse-song-youtube.mjs`：公式YouTube IFrame Player APIの遅延読み込み。動画音声の抽出はしない。
- `muse-song-dance.mjs/css`：曲・版・10/15/20/30秒・動作・カメラ選択、音源解析、試聴、サビ補正、管理・追加・非表示・復元、コピーと保存。
- `muse-reel-maker.mjs`：MUSE画面への統合、本人・衣装・髪・場所の引き継ぎ。
- `app.js`：既存状態保存へのメタデータ用ブリッジとクラウド適用後の通知。
- `index.html`、`reel-maker.mjs`、`sw.js`、`version.json`：読込・キャッシュ更新。
- `tests/muse-song-*.test.mjs`：解析・未確認値・時刻・英語指示・画像接続・バージョン分離のテスト。

## 使用手順

1. 「リール制作」→「音楽からダンスを作成」。曲と音源バージョンを選ぶ。
2. 未確認の曲は仮の振付セットを即時表示。音源開始秒数は空欄、プロンプト内もUNKNOWN。
3. 利用権のあるMP3/M4A/WAVまたはMP4/MOVを登録（音楽40MB・動画150MB・最大10分）。選択した曲/版との一致と利用権を確認する。
4. 拍・音響アクセント・サビ候補を端末内で解析。候補は「自動解析・要確認」。反復根拠がなければサビは空欄のまま。
5. 試聴し、サビ開始・終了を補正。確認チェック後にその版のサビを検証済みにする。拍・小節強拍の検証とは独立。
6. 以後は同じ曲/版を選ぶだけで、保存済みサビから使用区間を自動入力。同一ファイルのSHA-256が一致する場合は解析を再利用する。
7. サビより長い尺は延長せず、10/15/20/30秒の範囲で収まる短尺候補を提示。手動使用区間は、音源末尾を超えない範囲で明示的に指定可能。
8. カット別英語プロンプトをコピー。ChatGPT等で開始終了キーフレームを準備し、前の終了画像を次の開始へ再利用してMUSEへ渡す。本人の同一性、服、髪、照明、背景を固定。
9. MUSEの実際の生成尺に合わせて出力を切り、動画を接続。生成された音声をミュートし、利用権のある音源を後付けするかInstagram公式ライブラリから同じ版を選び、実際に聴いて開始位置を合わせる。

YouTube参照は20曲すべてに登録済み。公式プレーヤー内の位置を記録するか、公式リンクを外部で視聴し動画の長さとサビ位置を手動登録できます。動画IDを持つ別バージョンとして扱い、配信原曲や他の動画へ時刻を移しません。埋め込み不可・通信制限の場合は外部視聴に切り替えてください。

## 検証結果

- 全体 `node --test tests/*.test.mjs`：182件成功、失敗0。
- 既存リール関連テスト50件を変更前に成功確認。
- 関連JS/MJSの `node --check`、`git diff --check`。
- 静的サイトのためnpm等のバンドル/ビルド工程はありません。
- ChromeのUI：20曲表示、未確認値空欄、試験用に自作した100秒の合成WAVから120BPM・サビ候補推定、20～40秒に補正して試聴、検証済み保存、英語指示の20～25秒対応、再読み込み後の20秒自動設定を確認。
- YouTube公式プレーヤーのローカル埋め込みは読み込み失敗。エラー案内・外部参照への導線を確認。YouTube上の実楽曲サビは検証していません。
- MUSEでの実動画生成・iPhone Safari実機・複数端末でのクラウド同期の実地確認は未実施。

## 調査と制限

20曲の書誌・公式YouTube参照は調査済み。実楽曲20曲について音声本体は取得していないため、BPM・拍・サビ時刻・15/20秒推奨区間は全曲未確認、サビ検証済みは0曲です。仮数値42.0秒の登録はありません。試験データは合成音源のみで、本番ライブラリには混ぜません。

サビ検出は反復と音響特徴からの粗い候補であり、音楽的な意味や歌詞を理解する認識ではありません。強い音のピークも小節1拍目を意味しません。振付は楽曲ごとの制作方向・時刻・拍推定から組み立てるオリジナル案であり、公式振付や生成結果の完全同期を保証しません。参考優先モードはURLと時刻付きメモが必要。日本語メモは元資料として保持し、ChatGPT用指示では英訳して完全な英語プロンプトへ整えるよう指定します。

Meta公式のMuse Image/Muse Video発表は確認しましたが、利用者画面での厳密な対応尺・終了画像入力・指定音源入力の仕様は確定できませんでした。5秒のカットは計画単位で、対応生成尺を意味しません。非対応機能を必須にせず、開始画像+文章・後編集へフォールバックします。MUSEへの自動送信、動画の自動生成、Instagramへの自動投稿は追加していません。

音声解析は既存コードと新規の自前処理のみで、外部音声解析ライブラリを追加していません。追加ライセンスや課金APIはありません。YouTubeは公式IFrame APIと正規埋め込みを利用し、非公開API・音声ダウンロード・DRM回避は使いません。
