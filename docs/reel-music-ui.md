# リール音楽UI（v369）

音楽の初期選択をInstagram公式音楽へ変更し、その直下に検索入力・検索/人気/お気に入り・結果・選択中の曲を表示。接続設定は検索パネル末尾、任意のテンポ調整は折りたたみへ移動。検索前と結果0件の案内を追加。既存の認証、試聴、確認付き公開は変更しない。

## 歌詞

公式音楽から歌詞を取得できる仕様は確認できていないため、外部の歌詞取得や音源ダウンロードは行わない。ユーザーが権利を確認した歌詞/LRCを曲に保存できる。localStorageのOPSユーザー別キーで最大30曲を保持。入力欄が空の場合のみ、同じ公式音源IDに保存した歌詞を選択時に自動復元する。使用権の確認チェックは復元せず、字幕タイミングは既存の自動配置・LRC・タップで調整する。端末間同期はない。手入力中のテキストは自動で上書きしない。

## 検証

- Nodeの音楽解析・字幕テスト15件通過、変更モジュール構文確認。
- ローカルのモックAPI画面で初期公式音楽・検索・選択・歌詞保存・再読み込み後の自動復元・権利チェック解除・字幕自動配置を確認。
- 音声ファイル方式への切り替え後も字幕欄が表示されることを確認。
- Chromeの390×844表示で横溢れなし。iPhone Safari実機での確認は未実施。

追加の環境変数・外部サービス・DB変更はない。
