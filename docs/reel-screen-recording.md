# 画面収録音声・歌詞下書き・複数写真（v372）

音楽ファイル方式でMP4/MOV/M4Vの動画も選択できる。ブラウザの音声デコーダーで音声だけを取り出し、従来のビート解析・音声付きMP4制作に利用。動画の映像は出力に使用しない。音楽40MB、動画150MB。端末がコンテナやコーデックを読み取れない場合は、M4A等への変換を案内する。iPhoneの全収録形式を保証するものではない。

写真は4〜12枚。枚数を編集計画に渡し、テンポが遅い場合も長い区間を分割してすべての写真が登場する。繰り返しやコラージュの参照も実際の枚数を使う。

## 歌詞・字幕の下書き

音楽の利用権と送信同意を確認して専用ボタンを押す。端末で指定開始位置から15/20/30秒のモノラル16kHz PCM WAVを作り、reel-transcribe Edge FunctionからOpenAIのwhisper-1へ送る。動画の映像や選択区間以外は送らない。サーバー側で音声ファイルを永続保存しない（OpenAIのデータ取り扱いは同サービスの規約に従う）。API料金が発生することをUIに表示。

時刻付き認識結果を編集可能な字幕へ反映。歌声は誤認識があるため、内容と時刻の確認、利用権チェックが必要。長い認識区間は最大40文字の行に分割し、分割内の時刻は均等配分する。単語ごとの正確な歌唱同期ではない。認識中に入力・素材・区間が変わった場合は結果を自動反映しない。既存歌詞の置換は操作時に確認する。

## バックエンド

既存SUPABASE_URL、SUPABASE_SERVICE_ROLE_KEY、HANAKO_OWNER_USER_IDと、hanako_openai_key_readのVault接続または既存OPENAI_API_KEYを使用。新たなキーをクライアントに出さない。verify_jwt=trueに加え/auth/v1/userで実ユーザーを検証し所有者だけ許可。最大約1.1MBのリクエストと15/20/30秒の固定WAV形式を検証。認識先・モデルはサーバーで固定し任意URLを受け付けない。未設定時は接続設定を案内。DB変更なし。

## 検証

38件通過。各スタイル/50・120・200 BPM/4・5・8・12枚の全枚使用、音声変換・無音、未認証/別ユーザー/同意なし拒否、認識エラー、長文分割と字幕互換を検証。Chromeで音声付きMP4（15.96秒）を生成し、音声をデコードして15秒480044 bytesのWAVに変換。API実認識の精度とiPhone Safari実機の収録形式は未検証。
