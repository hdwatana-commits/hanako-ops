# 音楽からMUSEリールを作る使い方

この機能がOPSで作るものは「制作指示書」です。画像の生成指示、カット別の英語の動画指示、編集手順をテキストで準備します。指示書の保存はMP4動画の保存ではありません。

完成までの流れは、**OPSで準備 → ChatGPTで画像 → MUSEで短い動画 → 動画編集アプリで結合 → 音楽を追加してMP4保存**です。Instagramで音楽を後付けする場合は、編集アプリから無音MP4を書き出します。

## 1. 本人写真と見た目を決める（OPS）

顔・体格・髪・服装・背景を全カットでそろえるための準備です。

下のMUSE欄で「写真の役割：本人画像」→「写真を追加」。髪・服・場所は「こだわり」で指定するか、「SNSの髪型・服・場所・本人画像を取り込む」を使います。「写真の準備ができたら、曲の設定へ戻る」で音楽欄へ戻れます。

写真はプロンプトのコピーに含まれません。ChatGPTとMUSEには同じ元の写真・参考画像を手動で添付します。OPSから自動送信しません。

## 2. 曲・動画尺・動きを選ぶ（音楽欄）

最初は「20秒」「Instagramの参考から制作案」「標準」「正面固定」で進められます。

この音楽ルートでは、音楽欄の「動画尺」が完成尺です。下の汎用MUSE欄の「仕上げたい長さ」は別の企画に使います。「参考の衣装・場所・構図を使う」は参考スタイルを提案に反映する設定です。全編の公式振付を確認・再現したものではありません。

## 3. 音楽の使い方を選ぶ

音声ファイルがない場合は、サビ秒数を空欄のまま、仮の構成から画像・動画を準備します。最後にInstagramの公式ライブラリで使える同じ曲を選び、試聴して使用位置を合わせます。正確な拍・サビとの同期は未確認です。

利用権のある音源がある場合は「サビ未確認の曲を解析・確認する」を開きます。

1. 音源をアップロードして解析する。
2. サビ候補、開始・終了秒数を選ぶ。
3. 「候補・修正値を保存（要確認）」を押す。
4. 「選択した区間を試聴」で確認する。
5. 確認チェックを入れ、「このバージョンのサビを検証済みにする」を押す。

候補を選ぶだけでは試聴用の保存値は更新されないので、先に保存します。サビが希望尺より短い場合は、表示された短い候補を選びます。

音源バージョンとは原曲・MV・速度変更版などの区別です。参考リール内の時刻やYouTube版の時刻は、原曲の秒数へ転記しません。YouTube確認は視聴した動画版の位置を記録する機能で、音声をダウンロードする機能ではありません。

## 4. 制作指示書を準備する（OPS）

「この曲の制作指示書を更新」を押して確認します。曲や設定を変えると案も自動更新されます。

この音楽ルートでは、音楽欄の出力を使います。下の汎用MUSE欄の「画像準備と動画指示を作る」は別の企画を作る操作です。「制作指示書を保存（テキスト）」で保存されるものは文章です。

## 5. 開始・終了画像を準備する（ChatGPT）

「ChatGPTへ渡す画像作成指示をコピー」→ChatGPTへ貼り付け→本人写真と衣装・髪・場所の参考画像を添付して、画像作成を依頼します。

キーフレームは、動画の開始・終了姿勢の基準画像です。`KEYFRAME_01_START.png`は1本目の開始、`KEYFRAME_01_END.png`は終了画像です。文字・ロゴ・コラージュなしの縦9:16を1枚ずつ保存します。前カットの終了を次の開始に再利用すると、つなぎやすくなります。

## 6. CUTごとに動画化する（MUSE）

CUTは動画の1区間。20秒の初期案は4カットです。

開始画像と「CUT 1 の英語指示」をMUSEへ渡し、動画を保存。以降も番号順に作ります。カットの秒数は編集で使う長さの目安です。長い出力は後で切り出します。終了画像を指定できない画面では、開始画像と英語指示のEnding pose（終わりの姿勢）を使います。音楽時刻がUNKNOWNなら曲との同期は未確認です。

## 7. 結合・音楽追加・MP4保存（編集アプリ／Instagram）

編集アプリでCUT番号順に並べ、前後の姿勢を合わせて選択した完成尺に調整します。生成動画の音声をミュートし、利用権のある音源を付けるか、無音でMP4を書き出します。

無音MP4はInstagramへ読み込み、利用できる同じ曲を追加します。アプリ内の開始位置と原曲の秒数は同じとは限らないため、試聴で同じフレーズへ合わせ、確認して投稿します。

MUSE動画をOPS内で結合する機能はありません。下の「写真に、かわいいリズムを。」は、静止画4〜14枚から写真切替のMP4を作る別機能です。

## v391での案内改善

画面冒頭の7手順・用語説明・音源あり／なしの分岐・各設定への移動・素材欄から音楽欄への戻るボタン・現在の出力の案内を追加。出力順は「画像準備 → CUT別動画指示 → 結合と音楽追加」に整理しました。音源解析、動画指示生成、認証、投稿処理には変更していません。
